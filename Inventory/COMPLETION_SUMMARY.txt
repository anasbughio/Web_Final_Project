## 🧪 How to Test

### Test Admin Features
1. Register as admin (via role selection or API)
2. Login with admin account
3. Go to Products - Can create, edit, delete
4. Go to Users - Can manage all users
5. View Dashboard - Full permissions display

### Test Store Manager Features
1. Register as Store Manager
2. Login with manager account
3. Go to Products - Can create and edit
4. Cannot delete products
5. Users menu not accessible

### Test Employee Features
1. Register as Employee
2. Login with employee account
3. Can view products only
4. Cannot create, edit, or delete
5. Users menu not accessible

## 🌐 API Endpoints

### Authentication
- `POST /api/auth/register` - Register user
- `POST /api/auth/login` - Login user

### Products
- `GET /api/products` - List all
- `GET /api/products/:id` - Get specific
- `GET /api/products/low-stock` - Low-stock items
- `POST /api/products` - Create (Admin, Manager)
- `PUT /api/products/:id` - Update (Admin, Manager)
- `DELETE /api/products/:id` - Delete (Admin)

### Users (Admin Only)
- `GET /api/users` - List all
- `GET /api/users/:id` - Get specific
- `POST /api/users` - Create
- `PUT /api/users/:id` - Update
- `DELETE /api/users/:id` - Delete

See [API_REFERENCE.md](./API_REFERENCE.md) for complete details with examples.
